# Kanbo

A task board for small teams: keep projects on a three-column board (To do,
In progress, Done), assign tasks to team members, set due dates and talk
things through in comments.

Built with Django, the Django ORM on SQLite, and Django templates with one
plain CSS file.

## Getting started

Needs Python 3.12 or newer.

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python manage.py migrate   # creates kanbo.db and its tables
.venv/bin/python manage.py seed      # loads sample data
.venv/bin/python manage.py runserver
```

Open [http://localhost:8000](http://localhost:8000).

`manage.py seed` can be run again at any time: it replaces everything in the
database with the sample team.

## How it works

- **Members** are the team: a name and an email. There is no login; the
  comment form asks who is writing.
- **Projects** have a name and an optional description, and hold tasks.
- **Tasks** belong to a project and have a title, an optional description, an
  optional assignee and an optional due date. A task is `todo`, `in_progress`
  or `done`; any other status is refused. Deleting a task deletes its
  comments.
- **Comments** belong to a task and have an author and a body.
- A project's **progress** (tasks per status and the percent done) is worked
  out from its tasks when it is shown, never stored.
- The **board** shows a project's tasks in three columns, oldest first, and
  can be filtered to one member's tasks or to unassigned ones.

| Path                                   | What it is                                    |
| -------------------------------------- | --------------------------------------------- |
| `boards/models.py`                     | the tables, task rules, progress and board    |
| `boards/migrations/`                   | migrations, generated by `makemigrations`     |
| `boards/management/commands/seed.py`   | the sample team                               |
| `boards/forms.py`                      | project, task, comment and member forms       |
| `boards/views.py`, `boards/urls.py`    | pages and form actions                        |
| `boards/tests.py`                      | tests                                         |
| `templates/`, `static/kanbo.css`       | the HTML and its styles                       |
| `config/`                              | project settings                              |

## Changing the database

Edit `boards/models.py`, then:

```bash
.venv/bin/python manage.py makemigrations   # writes a new migration into boards/migrations/
.venv/bin/python manage.py migrate
```

## Tests

```bash
.venv/bin/python manage.py test
```
